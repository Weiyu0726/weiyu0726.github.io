THE DISCOVERY

Reconstructing a video is not the same
as understanding its action.

MiDiVLA starts with this gap. Two controlled experiments turn a multi-scale representation into a design for action supervision.

METHOD

What does the first-scale bottleneck give us?

Reconstruction + degeneration, extended by temporal composition.

Finding 2 motivates a first-scale action bottleneck. The two-branch model combines dynamics reconstruction loss L_dynam, including codebook and commitment terms, with degeneration loss L_degen. Clean features reconstruct B from A; perturbing S1 before VQ targets A, with detached codebook embeddings in the degeneration branch. Both branches, predictions, targets and losses remain visible throughout. One more thing introduces temporal composition loss L_comp as a third branch unfolding below the baseline. The final pipeline shows all three branches and their weighted total objective simultaneously. The second pair contributes only the first-scale action embedding aBC. No second-pair context input. The sum uses continuous embeddings after lookup and refinement, not discrete token identifiers. The decoder receives A, the summed action, and first-pair context. Predicted C is compared with observed target C.

We have learned an action representation.How does it become robot supervision?

VLA TRAINING

How do these tokens train a VLA?

From the paper training pipeline · Original image crops · Schematic tokens

The trained dynamics encoder annotates Internet video transitions with discrete first-scale indices as pseudo action labels; higher-scale context tokens are excluded. A frozen VQGAN visual tokenizer and the LWM-Chat-1M language backbone condition latent-action prediction on image and instruction tokens. The autoregressive loss supervises only action-token positions. For robot adaptation, the pretrained VLA is fine-tuned end-to-end on a small set of trajectories with ground-truth low-level actions. An executable action head is attached after the penultimate latent-action layer, and the latent-action head remains auxiliary supervision. At execution the policy uses the current image and instruction, with no future frame. Colored blocks are schematic, not measured code values.
